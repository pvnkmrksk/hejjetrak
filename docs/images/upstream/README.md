The coordinate illustration follows Fig. 1 of
[Moore et al. (2014)](https://doi.org/10.1016/j.jneumeth.2014.01.010), with the
world-axis orientation corrected in the upstream documentation. Preserve that
context when reusing it. These files are upstream reference illustrations,
not screenshots of HejjéTrac.

`../vfov-measurement.svg` is a new HejjéTrac diagram, not an upstream asset.
It illustrates the ordinary rectilinear-camera geometry described in the
hardware chapter and is distributed under the project license.
