Measured, with boundaries

Speed is useful.
Evidence is essential.

The tracking engine is tested on known-motion sequences and the complete 300-frame FicTrac sample. Reference comparisons retain declared rotation, path and heading limits.

The latest source measured 0.495 ms per tracking call on the predecoded sample. A separate native resource case ran 16 grayscale video sessions at 120 Hz using about 2.66 CPU cores and 350 MiB in total on a 12-core Apple M2 Pro. This excludes RGB capture and camera buses; it is not sixteen-camera capacity or a wattage measurement.

Resource cases, timing boundaries and limitations →

Read the scope

The pure Rust optimizer differs from upstream NLopt. A reference trajectory is not physical ground truth. Tracker-only latency excludes acquisition, conversion, encoding and display.

Sixteen tiled video windows have native evidence; sustained sixteen-camera capture at 120 or 240 Hz needs validation on the real hardware.

Opening on macOS

  1. Extract the ZIP and open hejjetrak.app. Allow camera access if you need it.
  2. This app is ad hoc signed, not notarized. If the developer cannot be verified, first verify the GitHub source. After attempting launch, use System Settings → Privacy & Security → Open Anyway, then confirm Open if you trust the app.
  3. Use that app-specific exception; do not disable Gatekeeper. A damaged-file or malware warning needs investigation.

Apple's first-launch guidance ↗

Opening on Windows

  1. Extract the ZIP completely and open hejjetrak.exe.
  2. The executable is unsigned. If SmartScreen shows an unknown-publisher warning and you trust the verified release, use More info → Run anyway when that option is available.
  3. Keep antivirus/SmartScreen enabled. Smart App Control or organization policy may block unsigned apps without a per-app exception; contact the maintainer/administrator rather than disabling protection. Allow OS camera access if needed.

Microsoft's SmartScreen explanation ↗ · Smart App Control limits ↗

Opening on Linux

  1. Extract the tar archive and open hejjetrak from its folder.
  2. The executable bits are preserved by the archive. If copying lost them, use your file manager's Allow executing file as program option for this executable.
  3. Use a graphical desktop with its ordinary graphics/camera drivers. Camera permissions follow your distribution. Ordinary launch needs no root access.
